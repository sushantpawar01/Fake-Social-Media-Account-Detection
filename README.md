# Fake Social Media Account Detection

A web application that detects fake and genuine social media accounts by fetching real profile data, extracting behavioral features, and running them through a trained ML ensemble model.

## Getting Started

### Prerequisites

- Python 3.11+

### Installation

```bash
cd fake_social_detection
py -3.11 -m pip install -r requirements.txt
```

### Train the Model

The trained `model.pkl` is already included. To retrain from the dataset:

```bash
py -3.11 core/train.py
```

### Run the App

```bash
py -3.11 app.py
```

Open your browser at `http://127.0.0.1:5000`

## How It Works

### 1. URL Input
Paste any social media profile URL. The app parses the platform and username automatically.

### 2. Data Fetching

| Platform | Method | Notes |
|---|---|---|
| GitHub | GitHub REST API (no auth needed) | Full data — followers, repos, join date |
| Instagram | HTML scrape with 4 User-Agent fallbacks | `og:description` served to social crawlers only |
| YouTube | HTML scrape of `/about` page | Join date via `joinedDateText` JSON field |
| Twitter, TikTok, Facebook, LinkedIn | Public HTML scrape | Limited — most block scrapers |

Instagram is handled by a dedicated fetcher that tries four User-Agent strings in order (Chrome, iPhone Safari, `facebookexternalhit/1.1`, `Twitterbot/1.0`) and uses the first response where follower count is non-zero. The `og:description` tag (`"673M Followers, 643 Following, 4,026 Posts - ..."`) is only reliably served to social media crawler UAs.

### 3. Feature Engineering
11 features are extracted from the raw profile data:

| Feature | How it's calculated |
|---|---|
| `follower_following_ratio` | followers / (following + 1) |
| `posts_per_day` | posts / (account_age_days + 1) |
| `bio_length` | character count of bio |
| `username_digit_ratio` | digits in username / username length |
| `username_has_random` | 1 if username has 4+ consecutive digits |
| `has_profile_pic` | 1 or 0 |
| `is_verified` | 1 or 0 |
| `followers` | raw follower count |
| `following` | raw following count |
| `posts` | total posts / repos count |
| `account_age_days` | days since account creation |

### 4. ML Model
A **VotingClassifier ensemble** (RandomForest + GradientBoosting) trained on a real Twitter dataset:

- **Dataset:** 5000 accounts — 2500 fake + 2500 real (from `archive.zip`)
- **Classes:** 0 = Genuine, 2 = Fake (no Suspicious class in training data)
- **Training accuracy:** 92.97% cross-validation
- **Pipeline:** StandardScaler + VotingClassifier (soft voting, equal weights)
- **Class handling:** `pipeline.classes_` is read dynamically so the code works regardless of which classes are present in the training data

### 5. Account Age Detection
The app tries 6 layers to find the real account creation date:

| Layer | Source |
|---|---|
| 1 | GitHub API — exact `created_at` field |
| 2 | JSON-LD structured data — `dateCreated`, `foundingDate`, `uploadDate` |
| 3 | HTML `<time>` element — `datetime` attribute |
| 4 | Open Graph meta — `article:published_time` |
| 5 | Visible text — "Joined March 2020" patterns (Twitter, YouTube, Facebook, LinkedIn) |
| 6 | ISO date fallback — any ISO timestamp near profile/created keywords |

YouTube's `/about` page exposes join date via the `joinedDateText` JSON field, which is parsed in layer 5.

### 6. Context-Aware Explanation
Signals are only shown when meaningful in context:
- "No profile picture" only fires if the account also has few followers
- "Missing bio" only fires combined with other suspicious signals
- Genuine accounts show positive signals like follower count and account age

## API

### `POST /api/detect`

**Request:**
```json
{ "url": "https://github.com/torvalds" }
```

**Response:**
```json
{
  "label": "Genuine",
  "confidence": 100.0,
  "score": 0.0,
  "age_source": "github-api",
  "platform": "github",
  "username": "torvalds",
  "probabilities": {
    "Genuine": 100.0,
    "Suspicious": 0.0,
    "Fake": 0.0
  },
  "features": {
    "followers": 292472,
    "following": 0,
    "posts": 11,
    "account_age_days": 5316,
    "follower_following_ratio": 292472.0,
    "posts_per_day": 0.0021,
    "bio_length": 0,
    "username_digit_ratio": 0.0,
    "username_has_random": 0,
    "has_profile_pic": 1,
    "is_verified": 0
  },
  "reasons": [
    "High follower count (292,472) — established account",
    "Account active for 5316 days"
  ]
}
```

`age_source` values: `github-api`, `json-ld:<key>`, `time-element`, `og:<prop>`, `joined-text`, `linkedin-since`, `keyword-iso`, `iso-fallback`, `default`.

`Suspicious` probability is non-zero only when the model's fake probability falls in the 35–65% range (borderline cases).
